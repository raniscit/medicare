A production-quality, full-stack AI-powered personal healthcare management platform. **MediCare AI** transforms complex medical laboratory reports, prescriptions, and hospital discharge summaries into clear, plain-language explanations, extracts actionable medication schedules, tracks biomarker trends over time, manages smart reminders, and enables family or caregiver collaboration with zero-exposure privacy.

---

## 🌟 Core Features Implemented

### 1. Medical Report Simplification
- Upload PDF, JPG, and PNG documents (Blood tests, CBC, Lipid Profile, LFT, KFT, Thyroid, Urine, X-Ray, Prescriptions, Discharge summaries).
- Automatic text extraction with OCR fallback for scanned reports.
- Extracts test parameters, numeric values, laboratory units, and normal reference ranges.
- Highlights abnormal values (HIGH / LOW) with visual status indicators and physiological biomarker context.
- Dual-display: Extracted laboratory figures side-by-side with simplified patient explanations.

### 2. AI-Powered Medical Summarization
- Automatic structured summaries generated by Gemini: Document Type, Report Date, Important Findings, Normal/Abnormal Parameters, Doctor Recommendations, Follow-up Instructions, and Precautions.
- **Two viewing modes**:
  - **Simple View**: Plain-language clinical explanation for patients and family.
  - **Medical View**: Preserved medical terminology and quantitative data for attending physicians.
- Direct download and print functionality for summaries.

### 3. Medication & Precaution Management
- Extracts prescribed medicine name, dosage, frequency, duration, meal timing (*Before food*, *After food*, *With meals*), special instructions, dietary recommendations, and precautions.
- Daily compliance schedule: Mark doses as *Taken* or *Missed* with precise timestamps.
- Add and edit medication schedules.
- Strict clinical guardrail: AI never modifies or prescribes medication dosages autonomously.

### 4. Smart Reminders & Follow-Up Alerts
- Reminders for medication times, doctor visits, follow-up tests, and general health checkups.
- Auto-extracts follow-up dates from uploaded discharge summaries and asks patients to confirm before activating reminders.
- Configurable recurrence: *Daily*, *Weekly*, *Monthly*, *Once*.
- Browser notifications and email alert integration.

### 5. AI Health Tracking & Longitudinal Trends
- Continuous timeline of patient biomarkers across all uploaded reports.
- Interactive historical trend charts (Recharts) for key parameters (e.g., HbA1c, Fasting Blood Glucose, Total Cholesterol, HDL, LDL, Triglycerides, Creatinine, TSH).
- **Two-Report Comparison**: Side-by-side comparative analysis of delta changes, reference limits, and trend direction.
- AI health insights explaining numerical trends without making unverified disease diagnoses.
- Unit-compatibility enforcement: Incompatible units are never falsely merged.

### 6. Family Member & Caregiver Integration
- Invite family members or professional caregivers via email.
- Granular permission matrix:
  - `can_view_reports`
  - `can_view_medications`
  - `can_view_reminders`
  - `can_view_trends`
  - `can_manage_reminders`
- Immediate access revocation at any time.
- Zero-exposure privacy guarantee: Medical data is isolated strictly by patient account.

### 7. Interactive AI Health Assistant (RAG)
- Conversational assistant powered by Retrieval-Augmented Generation (RAG).
- Multi-session chat history with session creation and deletion.
- Source citations displaying document names and page references for every answer.
- English and हिन्दी (Hindi) language support.
- Medical disclaimer guardrail: Strictly informational, never replaces professional medical counsel.

## 🚀 Getting Started

### Prerequisites
- **Node.js** v18+ and **npm**
- **Python** 3.10+
- (Optional) **PostgreSQL** database instance (defaults to SQLite if database URL is omitted)
- **Google Gemini API Key** (from [Google AI Studio](https://aistudio.google.com/))

---

### Backend Setup

1. **Navigate to the backend directory**:
   ```bash
   cd backend
   ```

2. **Create and activate a virtual environment**:
   ```bash
   # Windows PowerShell
   python -m venv venv
   .\venv\Scripts\Activate.ps1

   # Linux / macOS
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure environment variables**:
   Create a `.env` file in `backend/`:
   ```ini
   DATABASE_URL=sqlite:///./medicare.db
   SECRET_KEY=medicare-super-secret-jwt-key-production-change-this
   GEMINI_API_KEY=your_gemini_api_key_here
   ACCESS_TOKEN_EXPIRE_MINUTES=1440
   UPLOAD_DIR=./uploads
   ```

5. **Start the FastAPI server**:
   ```bash
   uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
   ```
   - API Server: `http://127.0.0.1:8000`
   - Interactive OpenAPI Docs: `http://127.0.0.1:8000/docs`

6. **Run Backend Test Suite**:
   ```bash
   python -m pytest tests
   ```

---

### Frontend Setup

1. **Navigate to the frontend directory**:
   ```bash
   cd frontend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure environment variables**:
   Create a `.env.local` file:
   ```ini
   NEXT_PUBLIC_API_URL=http://127.0.0.1:8000/api
   ```

4. **Run the Next.js development server**:
   ```bash
   npm run dev
   ```
   - Application URL: `http://localhost:3000`

5. **Build for Production**:
   ```bash
   npm run build
   npm run start
   ```

## 🔒 Security & Medical Ethics Guardrails

- **Zero Autonomous Diagnoses**: MediCare AI provides informational summaries and explains parameter changes strictly from document evidence. It never diagnoses conditions or modifies prescription dosages.
- **Tenant Isolation**: All database queries and vector chunks are scoped strictly by authenticated `patient_id`.
- **Granular Consent**: Family members only see features explicitly toggled by the patient and access can be revoked instantly.
- **Auditable Citations**: Every AI assistant answer references the exact source document name and page number.
